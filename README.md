# Data Roles Journey

A 12-month, hands-on path from Python basics to data engineering and AI.
Every lesson, mistake and project is committed here as I learn.

## Goal
Job-ready skills for Data Analyst, Analytics Engineer, Data Engineer, Data Scientist and AI/ML roles,
learned to working depth: build it, debug it, explain it.

## How this repo is organized
| Folder | What's inside |
|---|---|
| `00_journal` | Cheat cards for every lesson and a log of every error I hit and how I fixed it |
| `01_python` … `13_system_design` | Lesson exercises, one folder per skill, in learning order |
| `projects` | End-to-end portfolio projects built on real US flight data |

## Tools
Python · SQL · Git · VS Code · PowerShell, with pandas, Power BI, dbt, Snowflake, Airflow, Spark, AWS and more as the path continues.
